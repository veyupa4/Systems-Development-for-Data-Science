# CICIoT2023 — IoT Network Attack Analytics

## 📌 Project Overview
This project performs data analytics on the CICIoT2023 dataset from the Canadian Institute for Cybersecurity (UNB). The dataset contains network traffic from 105 IoT devices with 33 types of attacks across 7 categories.

## 🎯 Objectives
- Explore and visualize IoT network traffic data
- Detect patterns in attack vs. benign traffic
- Apply machine learning to classify attack types

## 📂 Dataset
- **Source:** https://www.unb.ca/cic/datasets/iotdataset-2023.html
- **Attacks:** DDoS, DoS, Recon, Web-based, Brute Force, Spoofing, Mirai
- **Devices:** 105 real IoT devices
- **Features:** 46 network traffic features
